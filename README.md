# 🍔 Food Ordering App UI

A modern and user-friendly **Food Ordering Mobile App UI** designed for a smooth and simple food-ordering experience.

## 📱 Project Overview

This project is a mobile UI/UX design for a food delivery application. 
The design allows users to browse food items, view food details, add items to the cart, and proceed to checkout.

## ✨ Features

- 👋 Welcome / Get Started screen
- 🍕 Food menu
- 🔍 Search food items
- 🏷️ Food categories
- 🎁 Promotions and special offers
- ⭐ Food ratings
- 🍔 Food item details
- 🛒 Add items to cart
- ➕ Increase/decrease item quantity
- 📝 Add order instructions
- 💰 View total price
- 💳 Checkout option
- 🏠 Simple bottom navigation

## 🎨 UI Screens

The project includes the following screens:

1. **Welcome Screen**
   - Food illustration
   - "Enjoy Your Food" message
   - Get Started button

2. **Menu Screen**
   - Search bar
   - Food categories
   - Promotions
   - Popular food items

3. **Food Details Screen**
   - Food image
   - Rating
   - Price
   - Description
   - Add-ons
   - Add to Cart button

4. **Cart Screen**
   - Selected food items
   - Quantity controls
   - Order instructions
   - Total price
   - Checkout button
